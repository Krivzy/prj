# Источники и лицензии

Новые skills — собственные рабочие инструкции на основе official docs, ссылки/даты внутри selective references. Это не официальное endorsement GSAP, Three, Motion, Next, 21st или OpenAI.

GSAP official skills исследованы на `greensock/gsap-skills` commit `aed9cfd3277740755f6bfc1155c7aa645403b760`. Полные upstream manuals с найденными ошибками не включены. MIT license и provenance/errata сохранены в gsap-animation-expert references.

Reused accessibility/performance/core-web-vitals: `addyosmani/web-quality-skills`, исходный закреплённый commit `afa8da942115f2961fdbfa80807ea0b232ff6c00`, MIT. У accessibility изменены только две строки порогов крупного текста по W3C. LICENSE сохранена рядом с reused skills.

- frontend-design: `anthropics/skills`, commit `dbd4588f9e1033efb41dad4bef2f7947c8993d44`.

Изучайте соответствующую лицензию конкретного source/skill до дополнительного распространения. Для дальнейшей установки используйте штатный skill-installer с pinned ref/path, не чужие непроверенные shell installers. Не запускайте upstream scripts просто потому, что они лежат в skill.
