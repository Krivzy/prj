# Minecraft Control Center0.7 — Overworld

Bukkit-плагин со встроенной Minecraft-панелью:14основных разделов и условные вкладки интеграций, реальные данные, HTTP/REST/WebSocket и SQLite. Интерфейс использует тёмный камень, зелёные акценты, Monocraft с кириллицей и Minecraft-анимации.

В0.6 добавлены живой каталог популярных плагинов с настоящей установкой JAR, постоянная PNG-карта всей сохранённой территории, аккуратные изображения миров, начальный локальный admin/admin и удаление пользователей. В0.7 добавлены пресеты ядра/Custom, интеграции LuckPerms/CoreProtect/AdvancedBan/AdvancedBanZ/Grim, монитор добычи блоков руды и штатный перезапуск через launcher v2.

## Восстановление и сборка

Нужны JDK25, Node.js24 и npm; Gradle wrapper9.2.1. Compile API — официальный Spigot26.3 snapshot20261004.024323-9; runtime-проверки перечислены в документах релиза. Для Paper/Purpur/Spigot используется общий Bukkit API и проверка наличия дополнительных функций. Folia требует другого scheduler и явно не поддерживается; Vanilla/Fabric/Forge не загружают Bukkit-плагины. Совместимость произвольных версий и форков не гарантируется.

```powershell
npm ci --prefix frontend --no-audit --no-fund
npm run test --prefix frontend
npm run build --prefix frontend
.\gradlew.bat --no-daemon -PskipFrontend=true build
```

Стандартная Gradle-сборка также выполняет frontend install/build/test. Итог: `build/libs/MinecraftControlCenter.jar` и SHA256. Один JAR содержит backend и статический frontend; отдельный Node.js production process не нужен.

Публичный снимок включает исходники, тесты, build configuration, документы и Monocraft/SIL OFL1.1. Миры, пользовательская SQLite база, runtime secrets/configuration, private backups, браузерные снимки и Minecraft-текстуры исключены. Владелец извлекает изображения из своего клиента; fallback остаётся работоспособным:

```powershell
python scripts/Extract-Assets.py --client "$env:APPDATA/.minecraft/versions/26.3/26.3.jar"
```

## Установка

Поместите JAR в `plugins/` совместимого Bukkit-сервера, запустите Paper и откройте `http://localhost:8080`. Новая пустая loopback-установка создаёт единственный admin/admin с правами администратора панели. Начальный пароль отмечен постоянно и допускается только локально без allow-lan/public-origin. Измените его в профиле перед удалённым доступом. `auth.bootstrap-admin:false` либо новая LAN/proxy-установка использует закрытый одноразовый `.setup-token`.

Обычные обновления сохраняют существующих пользователей, базу и миры. Разовая миграция конкретного локального owner на admin/admin отделена от обновления: её выполняют после normal stop и закрытой подтверждённой копии; `scripts/Migrate-Local-Admin.java` допускает одну исходную запись owner/Owner либо отдельно подтверждённый режим `--merge-existing-admin` для ровно двух Owner: owner/admin, проверяет хешы исходной базы и копии, сохраняет историю. Она никогда не запускается автоматически. Пользовательские credentials не входят в GitHub.

Обновление требует штатного перезапуска. Сначала сохраните текущий JAR и закрытую offline-копию database/configuration/миров; дождитесь успешного `stop`, замените JAR и запустите прежний launcher. Для отката верните прежний JAR после normal stop. Автоматический откат разовой миграции базы допустим только до последующих записей Paper и при совпадении её хеша с результатом миграции; иначе требуется отдельное восстановление с сохранением новых данных. Не используйте `/reload`.

Для Microsoft OpenJDK с известной сигнатурой G1 имеется [документированный обход двумя JVM-флагами](docs/JVM-G1-MITIGATION.md). Он сохраняет G1 и требует согласованного изменения launcher; короткая проверка запуска не заменяет длительный тест стабильности.

## Плагины и карта

Каталог использует Modrinth: поиск, сортировку популярности, подборку известных проектов, точную совместимость стабильного релиза и обязательные зависимости. Owner подтверждает план, MCC загружает и проверяет SHA512/JAR identity, атомарно сохраняет файлы в `plugins/`, затем показывает необходимость перезапуска. Это разрешённая установка стороннего Java-кода; metadata не гарантирует его качество. Проекты без подходящего релиза отображаются без активной кнопки установки. Обычные JAR, добавленные вручную, видны после запуска Paper. [Контракт каталога](docs/PLUGIN-CATALOG.md).

Карта использует постоянные изображения256×256 и zoom pyramid, как подход статичных тайлов Dynmap. Единственный ограниченный фоновый worker читает сохранённые FULL-records Anvil, без загрузки/генерации чанков через Bukkit. Первый обход рисует всю сохранённую поверхность постепенно, последующие показывают готовые изображения. Просмотр не запускает terrain rendering; живые позиции игроков обновляются отдельно. Это собственная реализация без полного набора renderer features Dynmap. [Карта и ограничения](docs/ISOMETRIC-MAP.md).

API/security: [API.md](API.md), [SECURITY.md](SECURITY.md), [LIMITATIONS.md](LIMITATIONS.md), [PERFORMANCE.md](PERFORMANCE.md). Native/browser проверки и границы доказательств: [VISUAL-AUDIT-0.7.md](docs/VISUAL-AUDIT-0.7.md). Исторические документы0.4/0.5/0.6 сохранены как история, включая проверенную установку0.5.

## Новые функции0.7

- [Пресеты ядра](docs/KERNEL-PROFILES.md): Vanilla, Vanilla+, Optimized и свои файлы. Только доступные публичные setters работают сразу; остальные изменения честно требуют restart. Launcher выполняет offline hook перед чтением ядром файлов, чтобы управляемый пресет восстанавливался после ручных правок. Custom не меняет файлы.
- [Интеграции](docs/INTEGRATIONS.md): условные вкладки LuckPerms/управления наказаниями/CoreProtect и Grim в «Честной игре». API вызовы встроены в наш интерфейс; неподдерживаемая версия показывает причину. Включённый AdvancedBan, AdvancedBanZ, LiteBans, BanManager или LibertyBans приостанавливает исполнение наказаний MCC, включая сохранённые записи; история сохраняется и не переносится автоматически. Полноценный адаптер наказаний есть для AdvancedBan/AdvancedBanZ; остальные известные провайдеры блокируют встроенные действия и показывают недоступность API. CoreProtect — ограниченный поиск истории; rollback этой версии не добавлен.
- [Честная игра](docs/ORE-MONITOR.md): реальные успешно сломанные блоки руды за1/5/10минут; Fortune не умножает счётчик. Цвет — сигнал темпа для проверки, не доказательство X-Ray и не автоматический ban. Указаны ограничения учёта установленных игроком блоков и сброса после restart.
- [Перезапуск и recovery](docs/SERVER-SUPERVISOR.md): Owner подтверждает штатный stop/save/start; Minecraft-анимация ждёт новый bootId. Без launcher кнопка объясняет отсутствие capability. После неожиданных завершений launcher делает ограниченные попытки с задержкой; crash loop останавливается для диагностики.
- [Переносимость](docs/BUKKIT-COMPATIBILITY.md) и [расход памяти](PERFORMANCE.md): ограниченные очереди/кеши, компактная история, SQL выборка до разбора JSON, меньшая частота снимков без зрителей.
