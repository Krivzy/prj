# Изображения и анимации

Игровые текстуры скопированы без изменения из установленного лицензированного Minecraft Java 26.3. SHA-1 клиента проверен по его официальным метаданным: e877b6a07acd633fb3bb475002175cec036e7b87. Оригинальная установка Minecraft не менялась. Авторские права на игровые изображения принадлежат Mojang/Microsoft; MCC не является официальным продуктом Minecraft.

`frontend/public/game-assets/catalog.json` связывает реальные идентификаторы API с текстурами, гранями блоков, метаданными кадров, областями атласов и названиями RU/EN. Русский перевод взят из установленного asset index 34: SHA-1 индекса 1e4e4a68dece1c0f51b8f93b45da8fe8da51bcd3, языкового объекта e5572ca1507224dc231272b15dbf45851d36d9af; оба проверены по метаданным. Английский перевод встроен в клиент. Это локальные ресурсы: браузер не обращается к сторонним CDN. Air — пустой слот. Мобы показаны портретами из текстур; это не полный рендер модели каждого существа. Специальные предметы, например щиты и книги, используют базовую текстуру модели; пользовательские NBT/скины и все составные слои предметов отдельно не отрисовываются.

`frontend/public/game-assets/art/hero.png` — новая иллюстрация, созданная встроенным imagegen. Парение, свечение, частицы и переходы реализованы кодом сайта. Настройка reduced-motion сокращает движение; скрытая вкладка приостанавливает декоративные анимации.

Публичный снимок содержит исходники экстрактора и renderer, а игровые PNG и генерируемый `game-assets` каталог исключены. Для восстановления изображений владелец использует свой установленный Minecraft-клиент: команда `scripts/Extract-Assets.py --client` приведена в [README](../README.md). Без извлечения остаётся fallback. Извлечение игровых текстур не восстанавливает созданную imagegen иллюстрацию hero.

Игровые PNG сохраняют исходные пиксели. В 0.8 экстрактор переносит from/to/rotation/UV реальных block-model элементов: плиты имеют половинную высоту, ступени — две части, ограды — свои стойки. ModelIcon строит статичный SVG с видимыми гранями и исходными текстурами; WebGL, серверный рендер и RAF для иконок не нужны. Модель ограничена 32 элементами, внешние texture URLs/невалидные координаты отклоняются. Дубли моделей хранятся по одному content ID. Анимированная грань использует первый объявленный кадр. Специальные builtin renderer/условные варианты модели и пользовательские NBT могут использовать прежний fallback; это не полный renderer Minecraft.

Карта — отдельная постоянная PNG-пирамида всей сохранённой FULL-поверхности Anvil. Она не использует эту геометрию предметов и не предоставляет строительство. [Контракт карты](PERSISTENT-IMAGE-MAP.md).

В MCC 0.9 курсор использует неизменённые PNG стандартного набора [Cursors Extended](https://modrinth.com/mod/minecraft-cursor), ранее известного как Minecraft Cursor. Источник закреплён на commit `a293ed53412d49c22107fb3cc409dbf68920998c` репозитория fishstiz/cursors_extended. Шесть PNG, пять исходных metadata JSON и MIT notice находятся в `frontend/public/assets/cursors/`; `ce-provenance.json` содержит исходные пути, SHA-256, размеры, hotspots и число кадров. Они включены в JAR и публичный снимок отдельно от исключённых игровых текстур Mojang. [Полное описание курсоров](CURSORS-EXTENDED.md).

Обычная стрелка и состояния действия, текста, запрета и захвата имеют исходный размер 32 × 32 и статичны. Оригинальный busy PNG — вертикальная полоса 32 × 256: восемь кадров по одному игровому тику, то есть по 50 мс. Анимация используется только при настоящем ожидании интерфейса; обычной стрелке не добавлены переливы, частицы или другие собственные эффекты. Клиентский мод не устанавливается и не исполняется: MCC использует только его ресурсы. Все 13 файлов Cursors Extended, включая metadata, MIT notice и provenance, получены без аутентификации с изолированного Paper и установленной версии Main и сверены побайтно со сборкой. Это проверка выдачи ресурсов; отдельный busy-кадр в браузере не захвачен. Старые `cursor-pixel.svg`, `cursor-pixel-active.svg` и четыре собственных PNG остаются неиспользуемыми совместимыми ресурсами. Каталог и modal адаптированы к узким экранам, длинные названия переносятся.
