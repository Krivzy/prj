# Visual audit MCC0.8

Финальный JAR: `c7d7aef8764b576c3ddcdf5f29dd960d1183da932a397a757f7f3ee59cd93651`. Полный обход выполнен на b34; финальное отличие — только два CSS-файла.

## Цель проверки

Общий Minecraft setting, понятные состояния OFF/loading/error/empty, адаптивные страницы, разные slab/stair изображения, доступный autocomplete и отсутствие скрытых сохранений при обычном выборе права.

## Логика и модели

TypeScript,78 frontend tests и статичный renderer: геометрия slab/stairs, поворот UV90, bounds/внешние texture URLs и неперекрывающиеся три видимые стороны куба. Это проверки модели/логики; они не заменяют просмотр работающей страницы.

## Browser review

Через обычные UI controls проверены все16 разделов работающего Paper-сервера при трёх ширинах:1280,768,390. Для48 обходов сохранены DOM-результаты и screenshots; глобального горизонтального overflow не обнаружено. Высота всех первоначальных desktop views отдельно не утверждается. Таблицы с большим объёмом данных используют локальную прокрутку.

Дополнительно проверены:

- LuckPerms: группа default, permissions/inheritance/metadata,20 подсказок реальных `minecraft.command.*`, выбор ArrowDown→Enter, context/expiry. Обычный выбор подсказки ничего не выдаёт; записи прав на основном сервере не выполнялись.
- Все24 формы событий, выбор наград в сокровищах и добавление второй награды в локальный draft. События на основном сервере не запускались.
- Четыре окна Честной игры и top5; честное empty-состояние, если отслеживаемых данных ещё нет.
- Широкий ItemStudio: дубовый блок, плита, ступени и ограда имеют разные геометрические модели. Предметы не выдавались.
- Автоматизации: каталог24 actions и серверная активность включённого профиля; существующие правила основного сервера не менялись.
- Настройки:12 переключателей модулей,5 пресетов и dry-run maximum с сохранением view/simulation. Настройки при просмотре не применялись.
- Нативный CSS-курсор, текстовый I-beam и fallback; browser console без зарегистрированных error в проверенных вкладках.

Найдены и исправлены три проблемы оформления в двух CSS-файлах: длинное название карточки событий захватывало место chevron, подписи количества/веса наград соприкасались, время/статус журнала переносились внутри короткого значения.

После установки окончательного c7 выполнен независимый просмотр пяти новых кадров: Events1280×960/768×960/390×892 и Audit768×960/390×892. Подписи разделены, тексты/стрелки не пересекаются, время и видимый tablet-status `completed` не ломаются. Mobile Audit показывает левую часть штатной scroll-table; находящиеся справа offscreen columns не объявляются pixel-проверенными. Шесть дополнительных DOM rows подтвердили отсутствие page overflow. HTTP index/CSS/JS отдаваемого Main совпали с финальным JAR; browser error logs в проверенной вкладке пусты.

Для карты, чата и нижних иконок мобов full-page capture давал неполное изображение. Обычные viewport-снимки после штатного UI-focus/zoom подтверждают карту и доступную форму, а следующий settled-кадр — lazy-иконки. Эти особенности съёмки не объявлены дефектами продукта; исходные кадры сохранены вместе с дополнениями.

## Особенности

Курсор — CSS native pointer без JSmousemove/canvas loop, с текстовым I-beam и системным fallback. Каталог SVG статичен и не запускает WebGL. Пользовательские данные, credentials и серверные worlds не входят в публичную копию.
