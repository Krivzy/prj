# Модульная память Codex и сохранение результата в GitHub

Переносимые правила для всех проектов и содержательных задач. Репозиторий содержит
обезличенную версию правил, структуру заметок и шаблоны. Адреса серверов,
пути конкретного профиля, credentials и полный конфигурационный файл сюда не входят.

## Поведение агента

- Каждый проект и задача: минимум `Index.md`, `Context.md`, `Results.md`.
- Существующие части проекта получают собственные заметки: Frontend, Backend,
  Database, Deployment и другие. Названия выбираются по реальному составу.
- Каждая содержательная задача сохраняется в GitHub с проверкой commit/ref.
- В Obsidian остаются навигация, решения, проверки и ссылки на сохранённый commit.
- Новые репозитории private по умолчанию. Public используется только с явным разрешением.
- При продолжении агент находит GitHub URL в Obsidian и восстанавливает нужный commit.

## Установка

1. Сделайте резервные копии глобальных `AGENTS.md` и `config.toml` своего профиля Codex.
2. Объедините [AGENTS.md](AGENTS.md) из этого репозитория с существующими глобальными
   инструкциями; сохраните правила инженерной работы и доступа к вашему vault.
   Не заменяйте весь существующий файл переносимым фрагментом.
3. Установите параметр из [config/project-docs.toml](config/project-docs.toml)
   на верхнем уровне своего `config.toml`, вне секций TOML.
4. Настройте доступ к закрытому Obsidian vault отдельно. Индексы, условные записи
   и обратное чтение с SHA-256 выполняет клиент vault.
5. Проверьте приоритет `AGENTS.override.md` и инструкции конкретного проекта.
   Проверьте загрузку правил в новом сеансе Codex.

Ожидается работающий доступ к Obsidian, Git и доступ к GitHub через Git CLI
или подключённый GitHub-коннектор. `gh` необязателен.
Правила управляют работой агента; отдельный фоновый процесс синхронизации не устанавливается.
Ошибки сети/прав отражаются как `pending push` и сообщаются пользователю.

## Безопасность и откат

Секреты и защищённые каталоги не публикуются даже в private-репозиториях.
Push не должен запускать неразрешённые изменения production.
Для отката локальной установки восстановите резервные копии глобального `AGENTS.md`
и `config.toml`; затем проверьте инструкции в новом сеансе.
